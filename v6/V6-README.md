# Cinematic 3D V6

Start with `V6-CHANGES.md`.

1. Run `python validate_v6.py` for offline source checks.
2. Install the packages in `requirements-v5.txt` in a supported Python environment.
3. Render V3/V4/V5/V6 stills at identical times and dimensions.
4. Use `review_v6.py` to create a contact sheet and basic exposure metrics.
5. Render moving test clips and manually approve before any full-length render.

V6 is additive. Original V3/V4/V5 files and source assets are retained. Runtime OpenGL rendering has not been verified in this build environment.
